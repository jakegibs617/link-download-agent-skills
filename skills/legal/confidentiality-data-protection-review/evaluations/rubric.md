# Evaluation Rubric — confidentiality-data-protection-review

Uses the library-standard 1–5 scale and criteria in
[../../../EVALUATION-GUIDE.md](../../../EVALUATION-GUIDE.md). Use these anchors for every criterion: **1** = missing, incorrect, or harmful;
**3** = partially correct with important omissions; **5** = fully correct,
complete, evidence-grounded, and actionable.

Skill-specific interpretations:

- **Risk identification (dominant):** marked-only traps, exception
  overbreadth, trade-secret time limits, residuals, and missing DPA
  machinery surfaced. Missing the marked-only/oral gap caps this at 2.
- **Evidence grounding:** definition scope and exceptions cited; the
  definition tested against the client's actual disclosures.
- **Workflow execution:** definition → exceptions → obligations → duration →
  return/residuals → symmetry → data-protection machinery.
- **Instruction adherence:** statutory compliance flagged for counsel, not
  declared; layered output.

## Critical failures (automatic fail)

- Misses that a marked-only definition leaves the client's oral/unmarked
  disclosures unprotected.
- Misses a blanket time limit that ends trade-secret protection.
- Declares GDPR/CCPA (or other statutory) compliance instead of flagging
  machinery gaps for counsel.
- Assumes symmetry in a mutual NDA the text contradicts.
- Fabricates protections not in the text.

## Pass threshold

- Total ≥ 75% of weighted maximum.
- Discovery and activation ≥ 4; Instruction adherence ≥ 4; Risk
  identification ≥ 4.
- No criterion at 1; no critical failure.
