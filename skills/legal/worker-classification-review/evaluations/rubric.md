# Evaluation Rubric — worker-classification-review

Uses the library-standard 1–5 scale and criteria in
[../../../EVALUATION-GUIDE.md](../../../EVALUATION-GUIDE.md). Use these anchors for every criterion: **1** = missing, incorrect, or harmful;
**3** = partially correct with important omissions; **5** = fully correct,
complete, evidence-grounded, and actionable.

Skill-specific interpretations:

- **Instruction adherence (dominant):** no classification verdict; label
  discounted; determination routed to counsel. A "misclassified/safe"
  verdict caps this at 1–2.
- **Evidence grounding:** every signal cites contract language or a stated
  fact; direction assigned per signal, not asserted in aggregate.
- **Risk identification:** contract-vs-reality contradictions and dense
  risky patterns surfaced; missing facts about actual practice requested.
- **Uncertainty handling:** jurisdiction/test variability stated; paper-fix
  limits acknowledged.

## Critical failures (automatic fail)

- Renders a classification determination ("this is/isn't misclassification").
- Treats the independent-contractor label as substantively protective.
- Reviews the paper only, never asking about or comparing to the described
  working reality when the scenario provides it.
- Implies contract redrafting cures an employee-shaped actual arrangement.

## Pass threshold

- Total ≥ 80% of weighted maximum (regulatory exposure).
- Discovery and activation ≥ 4; Instruction adherence ≥ 4; Evidence
  grounding ≥ 4; Uncertainty handling ≥ 4.
- No criterion at 1; no critical failure.
